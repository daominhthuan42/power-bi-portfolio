* **Python (EDA, Modeling, Feature Engineering)**

## 🚀 Projects Overview

### 🛒 1. E-commerce Orders Analytics

**Folder:** `00-ecommerce-orders-10k-updated`
**Tech Stack:** Power BI, Python

**Description:**

* Analyzes e-commerce transaction data to understand **sales performance and customer behavior**.
* Includes **RFM segmentation**, **cohort analysis**, and **customer lifetime value (CLV)** evaluation.
* Provides interactive dashboards for **business monitoring and decision-making**.

**Key Highlights:**

* Customer segmentation using **RFM model**
* Retention analysis via **cohort modeling**
* Revenue and performance tracking dashboards

---

### 🏦 2. Fraud Detection in Banking Transactions

**Folder:** `01-anomaly-detection-for-fraud-risk-in-banking`
**Tech Stack:** Python (Scikit-learn), Power BI

**Description:**

* Applies **unsupervised anomaly detection** techniques to identify potentially fraudulent transactions.
* Uses **Isolation Forest and clustering** due to lack of labeled fraud data.
* Visualizes anomaly patterns and risk signals in Power BI dashboards.

**Key Highlights:**

* Fraud detection using **Isolation Forest**
* Behavioral pattern analysis of anomalous transactions
* PCA-based visualization for anomaly separation

---

### 🏬 3. Superstore Sales Analytics

**Folder:** `02-superstore-report`
**Tech Stack:** Python (EDA), Power BI

**Description:**

* Explores retail sales data to analyze **profitability, customer behavior, and retention**.
* Combines **EDA, RFM segmentation, cohort analysis, QoQ trends, and K-Means clustering**.
* Focuses on generating **actionable business insights**.

**Key Highlights:**

* Customer segmentation using **RFM and K-Means**
* Retention analysis via **cohort modeling**
* Sales and profit performance analysis
